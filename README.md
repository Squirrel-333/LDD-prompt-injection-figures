#LDD Prompt Injection Figures

This repository contains the result figures for the paper
“Semantics as a Shield: Label Disguise Defense (LDD) against Prompt Injection in LLM Sentiment Classification”.

Contents

80 PNG figures visualizing model accuracy under:

clean prompts

class-directive injection attacks

few-shot prompting baselines

Label Disguise Defense (LDD) with different alias label pairs

For each model and alias label pair, we provide a shot-wise curve (2, 4, 6, 8 shots) comparing:

clean few-shot performance

under-attack performance

LDD-protected performance
